# r28：核心管理页「自动更新」选项 + 自动安装语义修复（2026-11-19）

需求：在 hub UI 里增加"自动更新 core"选项。

## 现状盘点（动手前）

- 设置页已有全局「更新设置」组（11-10 轮交付，e2e 已验）：启动检查 / 定时检查(6h) / 自动下载 / 自动安装 + 渠道/源/Token。
- 核心管理页只有**手动**按钮（检查更新 / ⬇ 更新 / 设默认 / 删除），没有任何自动选项。
- **语义缺陷（本轮修）**：后台自动链路 `pull_core(..., set_default=true)` 硬编码——
  「自动安装」勾不勾都切默认核心，`update_auto_install` 从未被消费（settings.hpp 定义→UI 回填→保存，
  行为层零引用）。即 UI 上"自动下载更新包"单开会**越权安装**。

## 实现（两级开关）

| 层 | 开关 | 持久化 |
|---|---|---|
| 哪类核心参与 | 核心管理页每张核心卡「自动更新」勾选框 | `startup_update.update_auto_maa` / `update_auto_maaend` |
| 处理粒度 | 设置页「自动下载 / 自动安装」（原有） | `update_auto_download` / `update_auto_install` |

行为矩阵（检查到新版后）：

| 卡片开关 | 自动下载 | 自动安装 | 行为 |
|---|---|---|---|
| ✗ | – | – | 仅提示「该核心未开启自动更新」 |
| ✓ | ✗ | – | 提示「设置页自动下载未开启」 |
| ✓ | ✓ | ✗ | **下载 + sha256 校验 + 登记为候选核心**，不切默认（提示可在核心管理页手动设默认） |
| ✓ | ✓ | ✓ | 下载 + 设为默认 + 同步全部同类执行器（原"完全体"行为） |

- 勾选框在 `draw_core_card`：每帧读 live 设置渲染，变更当帧经 `hub_->settings().update()` 落盘（线程安全，
  与设置页保存同一条路径）；顶栏提示行补两级开关说明。
- 旧配置兼容：`update_auto_*` 缺键 → 默认 false（ui_runner_test 第 11 节断言"绝不能凭空开启"）。

## 使用方式

想让 MaaEnd 自动跟上上游（当前 v3.1.0 可用）：核心管理页 MaaEnd 卡勾「自动更新」，
设置页勾「自动下载更新包」+「自动安装」，之后启动与每 6 h 定时检查会自动完成下载→校验→设默认→同步执行器。
只下载不切默认则不勾「自动安装」。
